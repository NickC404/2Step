# Contributing to 2Step

First off, thank you for considering contributing to **2Step**! It's people like you that make the open-source community such a great place to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs
* **Check the issue tracker**: We might already be aware of the problem.
* **Be specific**: Include your browser version, OS, and steps to reproduce.
* **Include screenshots**: Visual aids are extremely helpful.

### Suggesting Enhancements
* **Explain the value**: Why would this feature be useful to others?
* **Describe the workflow**: How would a user interact with this new feature?

### Pull Requests
1. **Fork the repo** and create your branch from `main`.
2. **Install dependencies** with `npm install`.
3. **Make your changes**. If you've added code that should be tested, add tests!
4. **Ensure tests pass**: Run `npm test`.
5. **Update documentation** if necessary.
6. **Issue a Pull Request** to the `main` branch.

## Code of Conduct
Please be respectful and kind to others in every interaction.

## Style Guide
* Use 4 spaces for indentation (consistent with the current project).
* Follow the existing file structure:
    * `src/`: Vue components and logic.
    * `popup/`: Static HTML and built assets.
    * `tests/`: End-to-end tests using Playwright.

Thank you for your help!
