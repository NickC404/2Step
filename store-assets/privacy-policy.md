# 2Step Privacy Policy

Last updated: 7 October 2026

2Step is a browser extension that shows whether the website you are visiting supports two-factor authentication. This policy explains what the extension does with your information.

## Summary

2Step does not collect, store on any server, transmit, sell or share any personal data. Everything it does happens on your own device.

## Information the extension accesses

**The address of your current tab.** 2Step reads the web address (URL) of the tab you are viewing so it can look up that site's domain in a list of sites bundled inside the extension. It uses the result to colour the toolbar icon and to fill in the popup. The address is used for that lookup only. It is not saved, logged or sent anywhere.

**Your tips checklist.** If you tick off items in the Tips tab, the list of ticked items is saved in your browser's local storage so it is still there next time. This stays on your device and is removed when you uninstall the extension.

2Step accesses nothing else. It does not read page content, form fields, passwords, cookies or browsing history.

## Information the extension collects

None. 2Step makes no network requests. It has no accounts, no analytics, no advertising and no tracking, and it has no server to send data to.

## Permissions

2Step requests one browser permission, `tabs`, which allows it to read the address of the current tab as described above. Chrome describes this permission as "Read your browsing history" because it gives access to tab addresses. 2Step uses it only to check the site in the active tab against its bundled list.

## Third parties

No data is shared with any third party.

The site information shown by 2Step comes from [2FA Directory](https://2fa.directory), a project by 2factorauth. That data is packaged with the extension when it is built, so using 2Step does not contact 2FA Directory.

The extension contains links to external pages, such as a site's own setup instructions. Those pages open in a new tab only when you click them, and they are covered by their own privacy policies.

## Limited Use

2Step's use of information complies with the [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq), including the Limited Use requirements.

## Changes to this policy

If 2Step's data practices ever change, this page will be updated and the change will be noted in the extension's Chrome Web Store listing before it takes effect.
